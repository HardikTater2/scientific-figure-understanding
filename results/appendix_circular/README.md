## Rationale for Quarantine: Evaluation Circularity

1. **Pseudo-Ground-Truth Source:** In `silver_grounding_v0.json`, the pseudo-ground-truth grounding edges between visual figure elements and text entities were constructed programmatically using lexical matching heuristics (trigram Jaccard, token overlap, and layout role rules).
2. **Circular Evaluation:** Evaluating rule-based heuristics and feature classifiers (trained on lexical similarity) against pseudo-labels generated by those very same heuristics creates a closed-loop circular evaluation ("heuristic evaluating heuristic").
3. **Artificial Metric Inflation:** Under circular pseudo-ground-truth, trivial lexical shortcuts and identical heuristics achieve artificially high precision and recall (e.g. tuned rules reaching $F_1 > 0.80$ and logistic regression reaching $F_1 \approx 0.71$), which do not reflect true human semantic grounding accuracy.
4. **Preservation:** In accordance with scientific honesty rules, these results have been removed from the paper's primary claims and quarantined in this appendix directory solely for archival completeness and historical auditability.
