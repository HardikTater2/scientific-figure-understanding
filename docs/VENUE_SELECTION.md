## 2. Pre-Submission Honesty Checklist

- [x] **Zero Simulated / Fabricated Results:** No simulated human ratings, no simulated VLM hallucination rates, no simulated Cohen's kappa.
- [x] **Reproducible Numbers:** Every number generated by executable scripts (`python scripts/reproduce_all.py`).
- [x] **Accurate Dataset Provenance:** Real arXiv figures labeled transparently as `silver_heuristic` (`data/scicap_subset/silver_grounding_v0.json`).
- [x] **Disjoint Splits:** Partitioned strictly by arXiv paper ID (`GroupShuffleSplit`) to prevent cross-split leakage.
- [x] **External Human Benchmarks Integrated:** Text-role accuracy on CHART-Info UB PMC, chart QA on CharXiv, entity extraction on SciERC.
- [x] **Assertion Tests in CI:** CI guardrails enforce provenance tagging and disallow pseudo-random generation of outputs.
- [x] **Multiple Comparisons Correction:** Holm-Bonferroni correction applied across all testing families (`src/evaluation/multiple_testing.py`).
- [x] **Open Research Licensing:** All datasets and code documented with CC BY-NC-SA 4.0 in `data/SOURCES.md`.
